Use a two-layer system:

* a **coverage code** for each subcriterion: `0 = absent`, `0.5 = partially covered`, `1 = substantively covered`;
* a **quality mark**, awarded in 5-point steps, which determines the weighted grade.

This avoids the problem of treating mere presence as quality. A student can completely cover an issue but do it poorly, or partially cover something at a relatively sophisticated level. It also retains the distinction from the seminar between knowing, applying and evaluating rather than rewarding concept-dropping alone.

# Coverage coding

I would use the `0 / 0.5 / 1` score principally as an **assessment-completeness flag**, rather than directly multiplying it into the percentage mark.

| Coverage | Interpretation                                                                                                            |
| -------: | ------------------------------------------------------------------------------------------------------------------------- |
|    **0** | Subcriterion is effectively absent or there is no assessable evidence of it.                                              |
|  **0.5** | Some relevant material is present, but an important part of the subcriterion is missing, underdeveloped or only implicit. |
|  **1.0** | The subcriterion is substantively addressed. This does **not** mean that it is necessarily done well.                     |

A `1.0` therefore permits the full grade range. For example, a student could completely discuss Grice but misunderstand several maxims and receive 35–45 for 1.1.

For consistency, I would normally place a **maximum of 55 on a 0.5 coverage score**. Partial coverage should not normally earn a 2:1 or First for that subcriterion because a substantive component remains missing.

# Percentage scale for each subcriterion

Each of the 16 subcriteria receives a percentage mark in **5-point steps**.

|    Mark | UK level          | General interpretation                                                                              |
| ------: | ----------------- | --------------------------------------------------------------------------------------------------- |
|   **0** | Not covered       | No assessable evidence.                                                                             |
|  **30** | Marginal Fail     | Very weak attempt; major misunderstanding or extremely limited relevance.                           |
|  **35** | Marginal Fail     | Some relevant awareness but substantial errors, omissions or lack of development.                   |
|  **40** | Third             | Basic relevant understanding/application but weak, largely descriptive and/or inaccurate in places. |
|  **45** | Third             | Adequate basic work with some appropriate material, but limited depth or consistency.               |
|  **50** | 2:2               | Competent but relatively descriptive or uneven; some useful application/evaluation.                 |
|  **55** | 2:2               | Sound and reasonably developed, but limitations prevent 2:1 quality.                                |
|  **60** | 2:1               | Good, accurate and appropriately applied/evaluated work.                                            |
|  **65** | 2:1               | Very good, well-developed reasoning with clear intellectual independence.                           |
|  **70** | First             | Strong conceptual command, critical engagement and synthesis.                                       |
|  **75** | First             | Very strong and sophisticated work, with sustained analysis and well-supported judgement.           |
|  **80** | Exceptional First | Exceptional conceptual, analytical and evidential quality well beyond normal First-class work.      |
|  **85** | Exceptional First | Outstanding integration, independence and intellectual sophistication.                              |
| **90+** | Exceptional First | Reserve for genuinely exceptional work showing unusually strong mastery and originality.            |

The important distinction is that the mark represents **quality**, whereas `0/0.5/1` records **coverage**.

# Weighting calculation

The weighting is straightforward.

For Criterion 1:

$$
1.1–1.4 = 7.5\% \text{ each}
$$

For Criterion 2:

$$
2.1–2.4 = 6.25\% \text{ each}
$$

For Criterion 3:

$$
3.1–3.4 = 5\% \text{ each}
$$

For Criterion 4:

$$
4.1–4.4 = 6.25\% \text{ each}
$$

The overall raw percentage is:

$$
\text{Overall} = \sum (Subcriterion\ Mark \times Subcriterion\ Weight)
$$

where the weighting is expressed as a decimal.

For example, a mark of 65 for 1.1 contributes:

$$
65 \times .075 = 4.875
$$

to the final percentage.

The 16 weighted contributions sum to 100%.

# Critical-component grade ceilings

I think this is important because otherwise the rubric becomes excessively compensatory. A student should not be able to omit an essential part of the assignment and obtain a First simply by doing exceptionally well elsewhere.

I would suggest the following **academic grade ceilings**, subject of course to any formal University regulations concerning incomplete assessment components.

### Ceiling 1: Core theory missing

If **1.1 = coverage 0** — effectively no meaningful engagement with Grice and/or Halpern:

**Maximum overall grade: 49% (Third).**

The assignment fundamentally assesses application of those course concepts. A 2:2 should require at least a basic demonstration of them.

---

### Ceiling 2: One substantive assignment component entirely omitted

The question has four substantive elements:

1. Grice and psychographic targeting;
2. Halpern skills applied by agencies;
3. evidence/training of critical thinking;
4. relationship between Gricean communication and critical-thinking application.

If **one of these four areas receives effectively zero coverage across the relevant rubric items**:

**Maximum overall grade: 59% (2:2).**

This prevents an incomplete answer reaching a 2:1.

If **two or more substantive components are absent**:

**Maximum overall grade: 49% (Third).**

---

### Ceiling 3: No critical analysis

If **2.4 = 0**, and the submission contains no meaningful synthesis, evaluation, counterargument or qualified judgement:

**Maximum overall grade: 59% (2:2).**

A 2:1 or First in a critical-thinking module should require genuine evaluation rather than accurate description alone.

I would apply the same ceiling where 2.1–2.3 collectively show essentially no critical evaluation even if concepts are accurately described.

---

### Ceiling 4: Required collaborative component missing

If **3.3 = 0 because neither required Peer Response has been submitted**:

**Maximum overall grade: 49% (Third).**

This is stronger than an ordinary weakness because the submission is missing one of the explicitly required assessment components and the task is specifically designed as collaborative learning.

If **only one of the two required responses is submitted**, I would code 3.3 as no more than `0.5` and suggest:

**Maximum overall grade: 59% (2:2).**

This seems a proportionate distinction between partial and complete non-participation.

---

### Ceiling 5: No scholarly evidence base

If there are **no academic sources at all**, or effectively no engagement with course scholarship:

**Maximum overall grade: 49% (Third).**

If the submission uses course material but **no meaningful journal research or wider academic reading**, particularly for empirical claims:

**Maximum overall grade: 59% (2:2).**

That aligns well with the stated expectation that the majority of reading should come from journal articles/course textbooks and should include wider reading.

I would *not* place a harsh ceiling merely because APA formatting itself is poor. APA errors should mainly affect 4.4 unless the citation problems are so severe that the sources cannot be identified.

# Additional band-integrity rules

I would add three small safeguards.

### To receive 60+ (2:1)

The student should normally have:

* no critical subcriterion scored `0`;
* all four substantive parts of the assignment represented;
* both Peer Responses present;
* evidence of academic journal reading;
* at least some genuine critical analysis rather than description alone.

### To receive 70+ (First)

In addition to the above:

* 1.1, 2.1, 2.3 and 2.4 should normally be at least **60**;
* no major criterion should average below **55**;
* Peer Responses must contain genuine critical engagement rather than polite commentary;
* wider reading and primary research should materially inform the argument.

This prevents a First arising from compensation for a major conceptual weakness.

### To receive 80+ (Exceptional First)

I would require:

* all four main criteria to average at least **70**;
* Criteria 1 and 2 to average at least **75**;
* no substantive subcriterion below **65**;
* unusually strong integration of theory, empirical evidence, counterargument and contemporary epistemic issues;
* the peer discussion should show intellectual contribution to the collaborative learning process, not merely fulfilment of the two-response requirement.

That makes the 80+ category genuinely exceptional rather than simply "a slightly better First".

# Recommended final-mark procedure

I would therefore grade each submission in five steps:

**1. Code coverage:**
`0 / 0.5 / 1` for each of the 16 subcriteria.

**2. Assign quality grade:**
`0, 30, 35, 40, 45 ... 80, 85, 90` for each subcriterion.

**3. Calculate weighted mean:**
using 7.5%, 6.25%, 5% or 6.25% according to the criterion.

**4. Apply any critical-component ceiling.**

**5. Report a stepped overall mark:**
use the appropriate 5-point value within the resulting UK grade band.

For example:

| Raw weighted result | Reported stepped mark |
| ------------------: | --------------------: |
|             35–39.9 |                **35** |
|             40–44.9 |                **40** |
|             45–49.9 |                **45** |
|             50–54.9 |                **50** |
|             55–59.9 |                **55** |
|             60–64.9 |                **60** |
|             65–69.9 |                **65** |
|             70–74.9 |                **70** |
|             75–79.9 |                **75** |
|             80–84.9 |                **80** |
|             85–89.9 |                **85** |
|                 90+ |                **90** |

This has one particularly useful property for subsequent grading: **the rubric tells us why a student received 65 rather than 70**, rather than the overall classification being based on a holistic impression after reading the post. It should also make grading across multiple submissions considerably more consistent.
